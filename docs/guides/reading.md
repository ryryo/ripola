# 文書を読む・端末に保存する

[起動手順](../../README.md#最初の起動)でローカル版を開き、Markdown・UTF-8 TXT・貼り付け、または横書き1段のテキスト層付きPDFを選びます。ファイルを選ぶとトップページに本文を準備します。「テキストのみ生成して読む」で読書画面へ進み、停止状態から開始します。PDFの抽出本文と元ページを照合してから再生してください。

貼り付け形式は自動判定が既定です。表示されたテキスト／Markdownを確認し、必要なら「変更」から手動指定します。テキストは`#`やリンク記号を残し、Markdownは見出し・リンク・ルビなどを読書用に抽出します。元の入力は保持します。ファイルはTXT・MD・PDF・青空文庫HTMLの形式を表示し、PDFの元ページも保持します。取り込みに失敗しても直前の原稿は残ります。

フォーム下の「サンプルで試す」には、吾輩は猫であるの音声付き冒頭約61秒、朝の図書館の短い黙読、全11章の黙読を3行で表示します。「音声付きで読む」「テキストで読む」「全文で読む」から直接始められます。準備済み音声の再生にはVOICEVOXの起動は不要です。

## 操作

- 通常画面は本文の下の操作バーから再生します。黙読は「戻る・再生・進む」、音声は「5秒戻す・再生・5秒進める」が中心です。全画面では停止中に本文中央の再生アイコンも使えます。
- フレーズ表示は中央の区切りを順に表示します。表示設定の「まとめる」「最小字数」で元フレーズをまとめられます。文末・段落・見出し・コード・表等を越えず、短い文末は最小字数より短くなる場合があります。停止時は操作列の下に前後の文を表示し、押すとその文の先頭へ移動します。
- 音声の速度は再生ボタンの下の操作列で変更できます。「一文」の戻る・進むは句点や段落で区切った文の先頭へ、「短い区切り」の戻る・進むは文の中の表示フレーズへ移動します。どちらも直接押せます。
- 全文表示は独立した読書モードです。現在位置を強調し、必要な行を描画します。手動scrollで追従を解除し、本文の選択・検索jumpは停止します。静的な全文も確認できます。
- 本文の上からフレーズ／全文表示、文字サイズ、ルビを直接変更できます。「表示設定」は書体、横書き／縦書き、まとめ表示、注視点ガイド、前後文脈の調整です。句読点の間は速度の横にある「句読点で間をとる」で切り替えます。端末標準が既定。Noto Sans JP／Noto Serif JP／BIZ UDPGothicは選んだ書体だけを同じサイトから取得します。準備・再計測中は停止し、完了後も明示再開を待ちます。失敗時は端末標準へ戻ります。
- ヘッダーの「配色を変更」から、サイト全体の「ライト」「ダーク」「端末に合わせる」を選べます。初期値は端末の配色です。ホーム・本棚・音声生成・読書画面・メニューで同じ配色を使います。
- 縦書きは上から下、右から左へ読みます。黙読・音声のフレーズ表示と全文表示、全画面に対応します。ルビは本文の右側に表示します。全文は左右のスワイプや横スクロールで移動し、PCの上下ホイールでも列を送れます。表示方向を切り替えると現在位置で停止します。
- 本文領域の右下にある全画面アイコンで本文領域を画面いっぱいに広げます。左右のページ余白・枠・ヘッダーを外し、再生中は本文と、有効にした注視点ガイドを表示します。本文のクリック／タップかSpaceで停止し、前後文脈・シークバー・速度設定を確認し、「フレーズ表示」「全文表示」を切り替えられます。PCでは再生中も画面下部へカーソルを移すとシークバーだけが現れます。Escまたは停止中の右下の全画面終了アイコンで戻ります。全画面への切り替え時は停止し、再生を待ちます。ブラウザの全画面が使えない環境ではページ内を最大化します。
- 文一覧は既定で閉じています。開く・操作する時に停止し、文を選んでも停止したままです。再生・再開するとPCの一覧もスマホのパネルも閉じます。
- 原文の位置を選ぶと停止して移動します。コード・表では自動再生を止め、原文確認と手動送りを促します。
- 進捗バーは句読点の間を含む再生時間で進みます。黙読速度の字数は空白・句読点を除く書記素で、休止込みの実効速度とは異なります。句読点ON時の追加休止は読点100ms・文末250ms・段落400ms・見出し600msで、個別時間の変更UIはありません。音声には固定休止を加えません。
- タブ非表示・画面リサイズ等で停止し、戻っても自動再開しません。再生中の番号・時間は固定し、停止すると確認できます。
- 再生中は、全画面・通常表示、黙読・音声のいずれも、対応ブラウザの標準機能で画面の自動消灯・ロックを抑えます。停止・再生終了・画面離脱で解除します。HTTPSで利用でき、端末の省電力設定や非対応ブラウザでは効かない場合があります。手動ロックやアプリ切り替え時は停止し、復帰後は再生操作を待ちます。

「本の操作」から先頭・末尾への移動、名前変更、作品情報、共有、キーボード操作を確認できます。黙読の保存削除とローカル音声の調整もここにあります。

| キー | 黙読 | 音声 |
| --- | --- | --- |
| Space | 再生・一時停止 | 再生・一時停止 |
| ←／→ | 元フレーズ移動・停止 | 原音声±5秒、再生状態維持 |
| Shift＋←／→ | 文移動・停止 | 文移動、再生状態維持 |
| ↑／↓ | ±100字/分（100〜3000） | ±0.25倍（0.5〜5倍） |
| Home／End | 先頭／末尾・停止 | 先頭／末尾・停止 |

入力欄、選択欄、button、slider、IME変換中、開いたダイアログでは通常の操作を優先します。Space長押しの連続切替を防ぎ、矢印の反復を抑制しています。R/V等の1文字キーはありません。音声5秒は倍速でも原音声の5秒で、2.5倍なら再生時間約2秒分です。

## 任意タイトルと名前変更

タイトルは空欄でも進められます。空白だけの場合も端末の現地日時（例 `2026/10/06 19:20:30`）を付け、明示した名前は保ちます。同時刻の別本文を名前だけで識別しません。

通常の読書は「本の操作」から変更できます。端末保存済みなら名前も保存され、未保存なら画面の名前だけを変更してから「端末に保存」で残します。ローカル音声は本棚または音声Readerの「本の操作」で変更し、再起動後も復元します。変更は本文・音声・区切りID・revision・生成cacheを作り直しません。公開音声サンプルの名前をサーバーへ書き換える機能はありません。名前は120文字までです。

本文はブラウザ内のWorkerで処理します。外部送信・解析API・ログイン・分析SDKを設けていません。上限はファイル20 MiB、本文100万UTF-16コード単位、PDF300ページです。複雑なPDFの読順は保証できないため、必ず抽出プレビューをご確認ください。

## 保存の範囲

黙読の文字/分、音声の倍速（0.5〜5倍）、表示設定とサイトの配色はこのブラウザのlocalStorageに自動保存します。文字サイズ・書体・ルビ・ガイド・まとめ表示・前後文脈・表示方式・本文の向きは黙読と音声で共有します。「表示設定をリセット」は本文の表示を初期値に戻し、サイトの配色・速度・句読点の間・読書位置・保存した本文は残します。保存済み本文を開く際も最新の表示設定を使います。全画面と再生状態は保存せず、ブラウザの保存が使えない場合もその回の設定変更と読書は続けられます。

「端末に保存」で本文1冊・元PDF・位置・設定を明示保存し、「保存を削除」で消せます。自動本文保存・端末間同期はありません。保存領域は、このブラウザのorigin内のIndexedDBです。PCの音声生成ライブラリーとは別で、再cloneや別端末へのバックアップを保証しません。共有端末では読書後に保存を削除できます。

通常取り込みにGoogle keyやCloudflare設定は不要です。音声生成を使う場合の送信・永続保存は[別ガイド](audio-generation.md)で扱います。BudouXは読みやすい表示境界を推定するもので、厳密な文法的文節・理解度向上を保証しません。

再生中は本文だけが切り替わり、番号・時間・残り時間は一時停止すると確認できます。ゲージは引き続き滑らかに進みます。音声同期の方式・スコア・開発用の検査結果は読書画面に表示しません。
