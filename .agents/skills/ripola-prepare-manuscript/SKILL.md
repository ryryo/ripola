# Ripolaの読み上げ用原稿を準備する

原本を保持し、取り込み可能なコピー、分割一覧、変更記録、未解決箇所を作る。書籍の内容を要約・改作する依頼とは区別する。

## 進め方

1. 対象原稿、読む目的、出力先、既存の整形結果を確認する。リポジトリの位置は実際のcheckoutから求め、作者の絶対pathを前提にしない。
2. [整形手順](references/cleanup.md)を読み、原稿全体の章構造、文字数、目次の重複、OCRの崩れを調べる。TXT/MDと、現在の取り込み対応PDFの違いを確認する。
3. Git対象外の作業先へコピーし、根拠のある整形だけを適用する。推測が必要な訂正は未解決として残す。発音だけの調整は読み辞書候補へ分ける。
4. [分割と対応記録](references/splitting.md)に従い、章・節と長さから境界を決める。固定の本数や文字数で機械的に切らない。
5. 元範囲の被覆・順序・除外箇所と、変更前後の差分を確認し、短い取り込みプレビューで見出しと段落を確かめる。

原稿、分割結果、対応記録には私的本文やpathが含まれる。`local-inputs/`または利用者が指定したGit外の場所へ保存し、公開サンプルへ混ぜない。既存出力を無断で上書きしない。

## 完了時に伝えること

出力先、各パートの順番・タイトル・文字数、修正と除外の要点、判断が残った箇所を示す。音声化まで依頼された場合は、完成コピーと読み辞書候補を生成作業へ渡す。整形だけの依頼から音声合成やデプロイを始めない。
